SURROGACY GUIDE - WEBSITE FILES
================================
Upload the whole folder (everything next to this file) to your host.
index.html must stay at the top level, with the img and i18n folders beside it.

Easiest free hosting (pick one):
  Netlify:  app.netlify.com/drop  -> drag this folder onto the page.
  Cloudflare Pages: dash.cloudflare.com -> Workers & Pages -> Create -> Pages -> Upload assets.

Domain: the files assume https://surrogacyguide.in
If you buy a different domain, ask Claude to rebuild the files for it
(it changes index.html, robots.txt and sitemap.xml).

After the site is live:
  1. Open search.google.com/search-console, add your domain, verify it.
  2. Submit  https://YOUR-DOMAIN/sitemap.xml
  3. Share the link on WhatsApp once to check the preview card.
